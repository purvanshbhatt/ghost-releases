# Ghost releases

Downloads for **Ghost**, the AI copilot for interviews, practice and meetings that remembers your context.

Get the latest build from the [Releases page](../../releases/latest), or visit the website for setup steps.

| Platform | File |
|---|---|
| Windows 10 and 11 | `Ghost-win-x64.zip` (portable: unzip, run `Ghost.exe`) |
| Linux (Debian, Ubuntu) | `Ghost-linux-amd64.deb` |
| Linux (any distro) | `Ghost-linux-x86_64.AppImage` |
| Android 11+ | `ghost-interview-copilot-release.apk` |
| Chrome, Edge, Brave | `ghost-chrome-extension.zip` (unzip, then Load unpacked in `chrome://extensions`) |

Every release lists SHA256 checksums in `SHA256SUMS.txt`.

The builds are not code signed yet, so Windows SmartScreen and Android may warn on first install.
